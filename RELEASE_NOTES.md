## Exp05-P1 correction represented in this release

The v1.0.0 Exp05-P1 workflow uses the capacity-matched fixed-AIGC branch required by the manuscript counterfactual definition. The archived primary design contains 638/640 strict same-regime three-branch configurations. Risk/trust net effects satisfy the archived capacity-plus-adaptation decomposition to numerical precision, and Figure 5 panel data are exported directly from the validated primary tables.

## Scope

This repository contains simulation code and numerical outputs; it does not include or depend on external empirical datasets. Publication-layout plotting code is archived for Figure 5. For other article items, the release provides the underlying machine-readable simulation data and experiment runners; exact journal-layout recreation is not claimed unless a corresponding builder/source file is present.
